## Open, serious

- [x] **AI** (from #524): `_BARE_URL` (`edit.py:953`) ends on a character class that excludes `)`, so a bare URL that ends in a balanced `)` (GFM keeps it in the link) is not protected. Probed on main: `see http://x.com/a(\*b) here` with one word edited saves `see [http://x.com/a(\\\*b)](http://x.com/a\(\\*b\)) there`, which renders as literal brackets with no link. The link is lost and the markdown shows as text. Fixed in 291e095f (#615).

## Open, minor

- [ ] **X** (from #501): a moved box is never clamped again. `replace()` skips `place()` once `_moved` is set (`page.js:2027`), and the `resize` listener (`:2081`) only re-wraps the thread. The resize and rotation case is already box 1 of `.scratch/follow-ups/comment-box-drag-gaps.md`. That box does not cover a box that grows taller, for example when a reply arrives, and pushes its controls below the visible area. Add that case to the same fix.
- [ ] **Y** (from #501): with touch, a drag starts after `MOVE_SLOP = 4` px (`page.js:2092`), but a touch counts as moved only past 8 px (`page.js:3394`). A 4 to 8 px drag on the band is therefore also an unmoved tap on `touchend` (`page.js:3397-3407`). The tap focuses the field, which raises the keyboard and docks the box that was just dragged. Use one threshold, or make the touchend skip a band press that started a drag. No touch test exists yet; see box 2 of the same follow-up file.
- [x] **Z** (from #503): `update` sets or clears the `generated` mark inside `change()` (`mcp.py:1364-1365`), before `move` and before the atomic write of `update_beneath`. If either of those fails, the update is refused but the mark has already changed. Only the setter or the key gets this far (`_check_generated` runs first), so no other token gains anything. The failed request still leaves a mark it should not have. Restore the mark when the write fails. Fixed in e9f5d6bb (#616).
- [x] **AA** (from #503): `create` with `generated: true` writes, publishes and commits the page, and marks it only afterwards (`mcp.py:1240-1243`). If the `docs.json` change fails, the create errors but the page stays unmarked, and a retry fails because the name is now taken. The caller can recover with `update` and `generated: true`. Fixed in e9f5d6bb (#616).
- [x] **AD** (from #517): `_BACKSLASH_ESCAPES` (`edit.py:929`) treats any literal `RDCMT` followed by ten upper-case hex digits as a placeholder. Probed: `a\RDCMT0123456789 here` saves `a\\RDCMT0123456789 there`. The rendered text is unchanged (`a\RDCMT0123456789`); only the source changes. Match only the tokens issued for this block. Fixed in 291e095f (#615).
- [x] **AE** (from #518): `_take_back_restart(c)` (`lifecycle.py:134`, defined at `:90-98`) sends its `DELETE /_/restarting` on the unpinned client `c`, while the `POST` that announced the restart went through `before.call`, which is pinned to the boot. On the `HubLost` path no token was read, and a DELETE without a token clears whatever is announced. If the hub was replaced in between, this clears the new hub's restart announcement, and its next service stop shows the stop banner. A DELETE that carries a token is safe since 181 C (random token per process). Send the take-back through `before`. Related: ticket 99 line 26. Fixed in e9f5d6bb (#616).
- [x] **AF** (from #520): Enter at the end of inline code in a table cell still writes the whole table as raw HTML. Probed on main: a cell `` `red` here `` edited to `<code>red<br></code> now` saves a `<table>` with `<td><code>red</code><br />now</td>`. `<code>red<br>&nbsp;</code> now` and `<code>red&nbsp;<br></code> now` give the same result; `<code>red<br>on</code> now` stays a pipe table. Nothing is lost and the page renders the same, but the table can no longer be edited on the page (ticket 137 line 20). The fix belongs in `_cell_breaks` and `_ends_its_cell` (`edit.py:866`, `:771`): a break that ends the code but not the cell counts as a break in the cell. Fixed in 291e095f (#615).
- [x] **AH** (from #523): `_LEADING_TOKENS` and `_COMMENT_TOKEN` (`edit.py:695-696`) also match footnote-citation placeholders, which `token()` draws from the same `RDCMT…` space (`edit.py:2337-2341`). The task code uses both (`edit.py:447`, `:454`, `:729`, `:732`). A citation before a typed `- [ ] milk` is skipped as if it were a comment and ends up inside the new task. A typed task whose only content is a citation is left as literal box characters. Pass only the comment tokens, or keep the two token sets apart. Fixed in 291e095f (#615).
- [x] **AJ** (from #525): `_RESULT_TEXT` (`send.py:217`) checks only `hash` on a successful `read`, but the callers use `now["text"]` (`send.py:398`, `:645-646`). A door answer with no `text`, or a `text` that is not a string, raises `KeyError` or `TypeError` instead of `SendError`. Nothing is written before the error. Add `text` to the `read` tuple. Fixed in e9f5d6bb (#616).
- [ ] **AK** (from #525): `Titles.read` (`hub/sheaf_view.py:38-46`) checks `key not in self._kept`, then reads `self._kept[key]`. Another thread's `clear()` between the two raises `KeyError`, and the Sheaf listing answers 500. Read with one `.get()`.
- [ ] **AL** (from #525): `_with_team` (`hub/handler.py:1304-1308`) catches only `ValueError` from `json.loads`, then expands `{**meta}`. A meta block that is valid JSON but not an object (a list, a string, a number, `null`) raises `TypeError`, and the relayed page answers 500. Leave such a block as it is, as the code already does for one that does not parse.
- [ ] **AM** (from #526): `pulling` and `pulled` each call `_page_of` (`hub/core.py:1740`, `:1755`). If the first call succeeds and the second raises, `pulled` moves on without ending the pull. `WriteLog._pulling` (`hub/writelog.py:209-216`) then keeps the address for the rest of the hub run, and every later disk write to that page is logged as the pull's. - [ ] **AN** (from #526): `restore_trash` (`hub/archive.py:254`) calls `os.path.lexists(src)` and then `os.lstat(src)` outside the lock, so a purge between the two leaks `FileNotFoundError` (500). - [ ] **AO** (from #526): `LiveDocument.refresh` (`hub/live.py:684-690`) keeps the old page and returns None when `_stamp()` gives None (a stat that fails, a file the hub cannot decide), even when the file did not move. - [ ] **AV** (from #534): `_writable` runs before `_text_writable` at all three sites: save (`hub/handler.py:1426-1427`), tick (`:1482-1483`) and share (`:1581-1582`).
