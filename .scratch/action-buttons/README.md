# Action buttons and tick boxes

Two kinds of task line, decided with Thierry on 2026-11-13 (grilling for AgentView's merge desk, session Kenji): something switched on and off is a **tick box**, drawn as a checkbox whose **label** ticks it too; something launched once is a **button**, drawn where its line is. The first user is AgentView's merge desk (`thinkingtoo/agentview`, `docs/specs/2026-11-13-merge-desk.md`), whose items are `- [ ] Merge owner/repo#N: …` lines.

A press still only ticks the box in the file; the hub calls nothing outside itself.
