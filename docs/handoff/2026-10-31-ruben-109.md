## #118: what the page-test hang was

- **Symptom.** On CI, the teardown of the #107 list test deadlocked inside Playwright: the main thread sat in Playwright's event loop, and the runner's load was 0.09. Every later page test timed out at 300 s, until the 45-minute job limit cancelled the run.
- **When it hung.** Only when the page tests ran after the non-page Tests step in the same job:
  - on 2ea73fa: 3 of 3 hung;
  - on main (bcdf311): one dispatched run hung, and the push run passed.
- **What did not cause it.** #108's save guard: main hung the same way without it.
- **Fix.** The test returned while its tick's reload was in flight; it now waits for the reload before teardown.
- **How it was run down.** By dispatching ci.yml on throwaway branches (`diag-118-pr`, `diag-118-main`, now deleted), changing only ci.yml:
  - the page step alone (both green);
  - Tests, then page with `--timeout-method=thread` (both hung, main thread stack in #118);
  - with the wait (both green).
- **Locally it never hung**, in CI order or under a CPU cap. Use `gh workflow run ci.yml --ref <branch> -f python=3.13` to rerun a CI-only symptom.
