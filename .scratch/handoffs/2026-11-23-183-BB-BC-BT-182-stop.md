## What changed

- **BB** (`edit.py`): `_bare_url_whole` checks a bare URL that contains a parenthesis against pandoc itself (`_pandoc_links_bare`, cached). GFM's rule for which `)` it keeps is not a count of parentheses (probed with pandoc 3.7).
- **BC** (`edit.py`): the module-level `_COMMENT_TOKEN` is gone. `_kept`, `_lone_as_text` and `_tags_as_text` take the pattern built from the comment tokens issued for the block (`_placeholders(comments)`).
- **182** (`hub/client.py`): `stays_down(reason, service)` is the single rule used by `ask_stop` and by the exit-row check in `_meet_version`. A service hub that answers `signal` is waited for. SPEC 8.4 and the docstring state that, under the service, a stray SIGTERM and a `systemctl stop` or logout cannot be told apart.
- **BT** (`edit.py`): a failed `_pandoc_links_bare` run raises `_Unread`, so `lru_cache` keeps nothing. `_bare_url_whole` turns it into EditError, which refuses that one save. This is the same pattern as `_emoji_looked_at`.

Tests: `tests/test_edit_url_followups.py`, `tests/test_edit_placeholder_tokens.py` and `tests/test_hub_upgrade.py`.
