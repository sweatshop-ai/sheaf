- [x] **The problem.** A page that a job rebuilds through the MCP door's `update` (with a fresh `expected_hash`) silently overwrites an edit a person saved in the hub a few seconds earlier; nothing tells the person. Add a per-document "generated" mark that makes the page read-only for text edits while keeping comments, replies, resolve, Ask and Tell working. Nothing in SPEC or in the door sets such a mark today (`git grep -i generat -- SPEC.md` finds nothing about it).
  Holds on main ea538771 (audit 2026-11-22): the mark is `docs.json`'s `generated` key (`src/sheafmd/mcp.py:940-947`), the hub refuses text writes with it (`src/sheafmd/hub/handler.py:1347-1352`), the door refuses another token's `update` (`src/sheafmd/mcp.py:921-938`); `uv run pytest tests/test_hub_generated.py tests/test_mcp_generated.py`: 21 passed, `sheafmd` imported from the worktree.

- [x] **Decide where the mark lives.** The owner chose (1), hub state in `docs.json`, on 2026-11-20. A `docs.json` without the field must still load (no mark), with a test.
  - (1) hub state in `docs.json` (SPEC 4.2, 8.3), set by `create`/`update` with `generated: true|false` and recording the setting token's name. Recommended, so "only that token or the key may change it" is enforceable.
  - (2) front matter `generated: true`: visible in git, but any writer can set or clear it.

- [x] **With the mark:**
  - page meta `edit: false` plus a `why` (`src/sheafmd/render.py:1145-1146`), no `E` key and no Edit in the menu, a short notice ("Generated by <token name>. Edits are not kept; comment instead.");
  - `POST /_/save` and task-box ticks refused with a clear message and a diagnostics row without the text;
  - `update` or create-over by another write token refused, accepted from the setting token or the key; a revoked setter leaves the mark, which only the key can clear;
  - `read` and `tools/list` expose `generated`.

  Audit on main ea538771 (2026-11-22), in the 21 passing tests above: meta `edit:false` + `why` (`src/sheafmd/hub/core.py:756-757`, `test_a_generated_page_has_edit_false_and_the_why_in_its_meta`); no Edit and no `E` (`src/sheafmd/page/page.js:402`, `:622`, `:3589` gate both on `canEdit`); save and tick refused with a row without the text (`handler.py:1381`, `:1437`; `test_save_is_refused_and_the_file_is_untouched`, `test_tick_is_refused`); another token refused, setter and key accepted, revoked setter (`mcp.py:921-938`; `test_another_write_token_cannot_update_a_generated_page`, `test_the_setting_token_and_the_key_may_update_a_generated_page`, `test_a_revoked_setter_leaves_the_mark_and_only_the_key_clears_it`); `read` and `tools/list` (`mcp.py:908`, `:132`, `:145`; `test_update_with_generated_true_marks_the_page_and_names_the_setting_token`, `test_tools_list_shows_generated_on_create_and_update`). **Missing:** the notice was never drawn on the page (only said on Ctrl+S); #573 draws it, with `tests/page/test_page_generated.py` (2 passed in CI run 45052712909); merged as d9a40b09.
